## 🧪 Testing Mindset

I write tests alongside features, not after them.

- **Angular:** unit tests for components, services, and pipes using **Jasmine** and **Karma**, with spies and mocks for HTTP calls
- **APIs:** request and response validation with **Postman**
- **Goal:** readable tests that catch regressions early

```ts
// Example: Angular component test with Jasmine
describe('LoginComponent', () => {
  it('should disable the submit button when the form is invalid', () => {
    component.form.setValue({ email: '', password: '' });
    expect(component.form.valid).toBeFalse();
  });
});
```
